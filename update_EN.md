## 🍁 14.0-pre1 - 26.3 - 2026-09-25

### 🌊 Core Features
- Minecraft upgraded to 26.3.
- Temporarily compatible with Carpet Extra features: Renewable Sand, Soul Sand Conversion, Renewable Wither Skeleton, and Empty Shulker Boxes Always Stackable.

### 🔥 Void Portal
- The following features are exclusive to the "Void Fifteen Worlds — Persisting Worlds / Persisting Worlds Array Island" worlds and only take effect in those worlds.
- Added: Island Village and Dappled Valley portals.
- Void Portal destination search radius: 128 blocks -> 256 blocks.

### 🎣 Fishing
- Coral Block added to the treasure loot pool.

### 🍀 Spirit Emerald
- Poplar Log added to the basic building materials convertible by the Stonecutter.

### 📱 Mods
- SubtleEffects, CustomSkinLoader and CarpetExtra are temporarily removed.

### 📱 Mod Configuration
- Carpet's redstone dust lag optimization is now disabled by default.
- CarpetExtra's better bone meal is now disabled by default.

### 🧭 Worlds
- New world "Departure Point — Island Village" ⭐ released.
- New world "Sunset Gorge — Dappled Valley" ⭐⭐ released.
- "Void Thirteen Worlds — Persisting Worlds" upgraded to "Void Fifteen Worlds — Persisting Worlds".
- "Void Thirteen Worlds — Persisting Worlds Array Island" upgraded to "Void Fifteen Worlds — Persisting Worlds Array Island".
- New "World Upgrade - Persisting Worlds & Persisting Worlds Array Island - 26.2->26.3" overwrite upgrade pack released. Extract it and overwrite the root of the corresponding save to make the "Departure Point — Island Village" and "Sunset Gorge — Dappled Valley" dimensions compatible.
